# Trace and debug references

This folder groups the documents that define debug, trace, and observability facilities for RISC-V systems.

## Included documents

- riscv-debug-specification.pdf
- RISC-V-N-Trace.pdf
- RISC-V-Trace-Connectors.pdf
- RISC-V-Trace-Control-Interface.pdf
- riscv-hart-trace-interface.pdf
- e-trace-encap.pdf
- riscv-trace-spec.pdf

## Notes

These specs are useful for platform validation, debug bring-up, and hardware instrumentation. They are not currently implemented as part of the project RTL but are documented here so they are easy to locate when system-level tracing or debug hooks are added.
