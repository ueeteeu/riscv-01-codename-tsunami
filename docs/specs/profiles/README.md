# Profile and extension references

This folder groups the profile documents and higher-level architecture sets that describe implementation classes and platform capabilities.

## Included documents

- rvb23-profile.pdf
- rva23-profile.pdf
- RISC-V_Profiles.pdf

## Notes

These profile documents define broad platform/application classes and help decide which subset of the ISA is expected to be supported. In this repo, the implementation is intentionally narrower: an educational RV32 core focused on core ISA, trap handling, and privileged CSR behavior.
